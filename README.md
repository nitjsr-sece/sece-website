# SECE Website

Official website of the Society of Electronics and Communication Engineers (SECE), NIT Jamshedpur.

## About the Project

This project contains the frontend of the SECE website, built using React and Vite. It provides a platform to showcase the society, its activities, events, and team.

## Tech Stack

- React.js
- Vite
- JavaScript
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/nitjsr-sece/sece-website.git
```

Navigate to the project directory:

```bash
cd sece-website
```

Install dependencies:

```bash
npm install
```

### Run Locally

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Build for Production

```bash
npm run build
```
